# Security Policy

## Reporting a vulnerability

Report security issues **only** through [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository (Security → Report a vulnerability).

Do **not** open a public issue for security reports. There is no separate security email for this project.
